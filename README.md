# GoIT JavaScript Homework 03 - Diziler ve Döngüler

Bu proje, GoIT Full Stack Developer eğitimi JavaScript modülünün üçüncü ödevidir. Bu çalışmada; dizilerin (arrays) yönetimi, dizi metotları, döngülerle (loops) veri işleme ve fonksiyonel programlama temelleri üzerine pratik yapılmıştır.
